# R8 palm electronics cover viewer

The viewer displays only hash-bound whole native R8 poses. No earlier assembly meshes are composed or interpolated into new configurations. The Palm electronics cover preset shows opaque P02 over the unchanged box; Cover underside gap uses display transparency to expose the lid. Both retain native fabrication geometry.

Run build_viewer.py after poses-input.json binds fresh native exports. Serve the parent directory on port8776 and open http://127.0.0.1:8776/viewer/viewer.html. A green banner requires the final source-bound independent report. Actual print strength, access, thermal behavior and comfort remain unqualified.

The local runtime /tmp/fingerworker-sensor-cad-20261022/bin/python supplies geometry libraries; this workstation path is not a packaged dependency.
