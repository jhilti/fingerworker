# R9 palm bracing viewer

Run `configure_native.py` after native R9 files arrive, then `build_viewer.py`. The builder requires at least one hash-bound whole native R9 export; it does not compose R8 parts into new poses or generate CAD motion. The four expected poses are neutral, adjusted rest a2, maximum28/p2/heavy and ISO13/p2/81.

New **Palm frame bearings** and **Bearing faces · isolated** views show the two P02-to-fixed-P01 contact faces. Gold outlines are analytic datum annotations only. The first view makes P01 translucent so the contact interface can be inspected; fabrication geometry stays intact.

Native regeneration and focused validation are pending until the corresponding evidence files are available. No load rating is implied. Frozen R8 remains untouched.
