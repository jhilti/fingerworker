# R7 compact adjustable rear viewer

Run `python3 build_viewer.py` after the hash-bound R7 native pose ZIPs and neutral STEP are supplied in poses-input.json. It shows only whole native exported configurations, with no composed or interpolated poses. P02 is one rigid printed block; P03 remains absent. Rear adjustment a is a manually matched side setting.

Serve the parent directory on port 8775 and open http://127.0.0.1:8775/viewer/viewer.html. The nominal PASS banner is gated on a final source-bound validation report. Physical strength, screw retention and comfort remain unqualified. The original hand scan registration is unchanged and approximate.

The workstation geometry runtime `/tmp/fingerworker-sensor-cad-20261022/bin/python` supplies numpy, trimesh and the optional spring display decimator. This absolute runtime is not a packaged dependency.
