Flat132 R20 prototype: organic palm support, rounded thumb recesses on both sides, inboard 25 mm strap slots and separate solid rear supports with integral locating pins.

- CAD source, firmware, iOS app, KiCad electronics, BOMs and technical revision history are in the repository.
- `Flat132_R20_neutral_final.zip` and `Flat132_R20_final_AP214.step` are the current native CAD exports, including reference hardware.
- `Fingerworker_R20_3D.zip` contains the self-contained offline 3D viewer. The live viewer is at https://jhilti.github.io/fingerworker/.
- `Historical_Bambu_Projects_through_R18.zip` archives 24 existing projects. These are **not R20 print files**.
- `Historical_Mechanical_Drawings_RevA.zip` archives earlier metal-part drawings. `Electronics_RevA_Technical_Exports.zip` contains prototype fabrication, assembly and sourcing data.
- `SHA256SUMS.txt` verifies all six downloads.

R20 has no new Bambu project or slice. Printing setup remains deferred. Locating pins support only spring-free, unloaded trial assembly; four M3×8 screws in their inserts are required before any spring force, including rest preload. Read the R20 assembly instructions in the repository. Physical load qualification, print fit, electronics commissioning and calibration remain open.

Personal orders/scans, runtime environments, downloaded manufacturer originals and redundant generated artifacts are excluded. No new open-source license is granted by this publication.
